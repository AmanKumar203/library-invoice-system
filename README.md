# Modern Study Library — Invoice & Membership Dashboard 📚⚡

A professional, high-performance web application designed for library owners and co-working spaces to generate executive tax invoices, manage student memberships, track payments, and share PDF receipts directly via WhatsApp.

---

## ✨ Key Features

- 🧾 **Executive-Grade PDF Invoices**: Generates A4 PDF invoices with custom library branding, student photos, itemized tables, GST breakdowns, digital verification seals, and scannable QR codes.
- ⚡ **1-Click Quick Fill**: Demo and test invoices in 1 second with pre-configured student profiles.
- 💬 **Direct WhatsApp Sharing**: Download invoice PDFs and open WhatsApp Web directly with pre-formatted invoice text.
- 📊 **Real-time Analytics Dashboard**: Track Total Revenue, Active Students, Paid/Partial/Unpaid metrics, and revenue breakdown charts.
- ⚙️ **Custom Library Branding & Settings**: Configure Library Name, Contact Phone, Email, Tagline, and Default Rates directly in your browser (`localStorage`).
- 🌓 **Dark & Light Mode**: Ultra-sleek modern UI with vibrant gradients and glassmorphism.
- 📱 **100% Mobile Responsive**: Perfectly tailored for Desktop, Tablet, and Mobile screens.
- 🔒 **Zero-Server Dependency**: 100% client-side privacy-first web application.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Vanilla CSS with CSS Variables, Grid, and Glassmorphism)
- **Modern JavaScript (ES6+)**
- **jsPDF** (Client-side Vector PDF Generation)
- **QRCode.js** (Dynamic Receipt Verification)
- **LocalStorage API** (Persistent Offline Data Storage)
